# CATI downstream workflow

The complete documentation for the CATI downstream workflow is integrated into the repository's [main MAGFlow README](../README.md#cati-downstream-analyses).

This directory contains the independent downstream Nextflow entrypoint (`main.nf`), Farm22 production and smoke-test launchers, modules, scripts, environment definitions, and example manifest. It does not modify or invoke the core MAGFlow `../main.nf` pipeline.
